# TV Shows Organizer

סקריפט לסידור אוטומטי של קבצי וידאו וכתוביות - משנה שם לפורמט אחיד, ומעביר אותם לספריית TV מסודרת לפי סדרה/עונה.

## מה הוא עושה

1. סורק תיקיית מקור (`SOURCE_DIR`) ומזהה קבצי וידאו וכתוביות (`.srt`) לפי תבנית שם עם תג פרק (`S01E02` או `1x02`)
2. משנה שם לפורמט אחיד: `Series.Name.S01E02.Episode.Name.ext`
3. **מושך את שם הפרק** מ-TheTVDB (v4 API) ומוסיף אותו לשם הקובץ - כולל כמה אסטרטגיות חיפוש אם השם המדויק לא נמצא (ראה בהמשך)
4. מעביר את הקבצים לספריית הספרייה (`LIBRARY_DIR`), עם זיהוי אוטומטי של תיקיית העונה הנכונה (או יצירתה אם אינה קיימת)
5. וידאו - **מועבר** (move), כתוביות - **מועתקות** (copy, המקור נשמר)
6. מציג preview מלא של כל השינויים המתוכננים **לפני** ביצוע בפועל, ומבקש אישור

## הגדרות (בראש הקובץ)

```python
SOURCE_DIR  = r"C:\Elad\TV"       # תיקיית המקור לסריקה
LIBRARY_DIR = r"H:\TV Shows"       # ספריית היעד המסודרת
TVDB_API_KEY = "..."                # מפתח API של TheTVDB v4
```

## תבנית זיהוי שם קובץ

התבנית מזהה כל דבר שמסתיים בתג פרק בפורמט `SxxExx` או `AxB`:

| קלט | מזוהה כ- |
|---|---|
| `Breaking.Bad.S01E02.720p.mkv` | סדרה: `Breaking Bad`, פרק: `S01E02` |
| `the.bear.1x05.mp4` | סדרה: `The Bear`, פרק: `S01E05` |
| `שם.בעברית.S02E10.srt` | מזוהה, אך **לא** ייעשה חיפוש ב-TVDB (ראה למטה) |

קבצים שלא תואמים לתבנית, או עם סיומת לא מזוהה, פשוט מדולגים - בלי שגיאה.

## חיפוש שם פרק ב-TheTVDB

**סדרות בעברית מדולגות אוטומטית** - אין חיפוש בכלל אם שם הסדרה מכיל תווים בעברית, כי TVDB הוא מאגר אנגלי בעיקרו.

לסדרות באנגלית, אם החיפוש הראשוני לא מוצא התאמה, הסקריפט מנסה **חמש אסטרטגיות** נוספות בסדר, עד שאחת מצליחה:
1. השם המלא כפי שהוא
2. בלי מילת יידוע בהתחלה (`The`/`A`/`An`)
3. בלי קידומת מדינה/שנה בסוף (`Us`, `Uk`, שנה בת 4 ספרות וכו׳)
4. שתי המילים הראשונות בלבד (לשמות ארוכים)
5. וריאציות עם מקף בין מילים (`Spider Noir` → `Spider-Noir`)

תוצאות חיפוש נשמרות ב-cache לכל הרצה (`_TVDB_SHOW_CACHE`), כך שלא נשלחת בקשת API כפולה לאותה סדרה גם אם יש לה כמה פרקים בתיקייה.

אם גם שם הפרק שחוזר מ-TVDB הוא בעברית - הוא **מדולג**, לא נכנס לשם הקובץ.

## לוגיקת מיקום בספרייה (`H:\TV Shows`)

| מצב | תוצאה |
|---|---|
| הסדרה לא קיימת בספרייה | נוצרת תיקיית סדרה חדשה |
| הסדרה קיימת, עם תיקיית עונה תואמת (`Season 01`, `S01`, `Series 1` וכו׳) | הקובץ נכנס לתיקייה הקיימת |
| הסדרה קיימת עם תיקיות עונה, אך לא לעונה הזו | נוצרת תיקיית עונה חדשה |
| הסדרה קיימת **בלי** תיקיות עונה כלל (מבנה שטוח) | הקובץ נכנס ישירות לתיקיית הסדרה, בלי ליצור תיקיית עונה |

קבצים עם שם יעד שכבר קיים **לא נדרסים** - מדולגים עם אזהרה.

## הרצה

```bash
python tvshows_organizer.py
```

אין תלויות חיצוניות להתקין - הסקריפט משתמש רק בספריית התקן של Python (`urllib`, `json`, `re`, `shutil`, `os`, `time`).

הריצה תציג:
1. רשימת סדרות שזוהו, עם ציון אם הן חדשות בספרייה או קיימות
2. תצוגה מקדימה מלאה של כל שינויי השם המתוכננים
3. בקשת אישור (`Y`/`N`) לפני שמתבצע כל שינוי בפועל

בזמן ההעתקה/העברה מוצג progress bar חי עם אחוז התקדמות, מהירות, ו-ETA.

## הערות חשובות

- **כתוביות מסונכרנות תמיד לשם הווידאו התואם** - גם אם שם הקובץ המקורי של ה-`.srt` שונה מזה של הווידאו, השם הסופי שלו יתאים בדיוק (כולל אותיות גדולות/קטנות) לקובץ הווידאו של אותו פרק, כדי שנגני מדיה יזהו אותם כזוג
- **אין דריסה שקטה** - בכל שלב (סידור ראשוני או העברה לספרייה), אם קובץ עם השם החדש כבר קיים ביעד, הקובץ המקורי מדולג ומופיע ברשימת השגיאות בסיום
- הסקריפט **תמיד** מבקש אישור לפני ביצוע שינויים בפועל - אין מצב "הרצה שקטה" אוטומטית
